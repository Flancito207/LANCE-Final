# LANCE-Final

Sitio web para LANCE UANL para FCFM.

## Descripción del proyecto

LANCE-Final integra la distribución base de LANCE-uanl con una estética institucional actualizada de la UANL y la sección de **Pósters de Investigación y Divulgación** del repositorio LANCE.

## Instalación y uso

1. Clona el repositorio.
2. Abre `index.html` en tu navegador.
3. Navega a `graficas/graficas.html` para ver la sección de gráficas en tiempo real.

No requiere pasos de compilación ni dependencias adicionales.
